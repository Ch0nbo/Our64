# Our64 error codes

Each error screen names its cause, the fix, and one of these codes.

| Code     | Screen                                                                          | Cause                                                                                                                                                                       | Fix                                                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OUR-0101 | (retired)                                                                       | No .z64, .n64 or .v64 file in `sd:/wiiu/our64/roms`. Since step 6 this is not an error: Our ROMs shows "No games yet" and where to copy them                                | Copy a ROM there from a computer, then start Our64 again                                                                                                                           |
| OUR-0102 | NO SD CARD                                                                      | The SD card is missing or could not be read                                                                                                                                 | Put the card back in, then start Our64 again                                                                                                                                       |
| OUR-0103 | START OUR64 FROM THE WII U MENU                                                 | Started without Aroma's code area (another launcher)                                                                                                                        | Start Our64 from its Wii U Menu icon with Aroma running                                                                                                                            |
| OUR-0104 | CAN'T READ THE GAME                                                             | The ROM file could not be read when chosen in Our ROMs: the file is damaged, or the SD card or USB drive holding the ROM folder could not be read                           | Put the SD card back in firmly, or check that the USB drive is plugged in firmly (whichever holds the ROM folder), or copy the file again from a computer; B goes back to Our ROMs |
| OUR-0105 | USB DRIVE NOT FOUND / ROM FOLDER NOT FOUND                                      | The ROM folder chosen in Settings > Games is on a USB drive that is not connected or has no FAT32 or exFAT partition Our64 can read, or the folder was deleted              | Plug the drive in and start Our64 again, or press A to use the SD card for now; choose another folder in Settings > Games                                                          |
| OUR-0201 | Pause menu red message; COULDN'T SAVE when closing                              | An in-game save or the autosave did not reach the SD card: the message says which and what is safe; Exit stays on the menu once, its item then reads "Leave without saving" | Check the card's lock switch or free up space on a computer, then play again                                                                                                       |
| OUR-0202 | Couldn't save to Slot N / Couldn't keep a backup first / Couldn't delete Slot N | A save state, or the Undo card kept before an overwrite, load or reset, could not be written or deleted; nothing else changed                                               | Delete a save state to make room, or check the card's lock switch, then try again                                                                                                  |
| OUR-0203 | Our Settings, Our Controllers, Edit buttons                                     | A setting, the rumble switch or a button mapping could not be written to `config/`; the value shown goes back to what is on the card                                        | Check the card's lock switch or free up space, then try again                                                                                                                      |
| OUR-0204 | Our ROMs: "Couldn't delete <game>"                                              | X's Delete could not move the game's file to `trash/N64/` (the card is locked or full); the game stays in the list                                                          | Check the card's lock switch, then try again                                                                                                                                       |
| OUR-0205 | Settings > Games, the line under the header                                     | Fetch covers could not write a cover to `art/` (the card is locked or full); the fetch stops, and the covers saved before it stay                                           | Check the card's lock switch or free up space, then fetch again                                                                                                                    |
| OUR-0301 | Loading: "The autosave ... can't be used"                                       | The game's autosave is from another Our64 version, for another game, or damaged; it is kept as `resume-a/b.unused.o64s`                                                     | A starts the game from its title screen; B goes back to Our ROMs                                                                                                                   |
| OUR-0302 | Load state: "Slot N can't be loaded"                                            | A save state is damaged or from another Our64 version (found when read); nothing changed                                                                                    | Delete it (Y, or minus on a Wii Remote) and save there again                                                                                                                       |
| OUR-0401 | Settings > Games, the line under the header                                     | Fetch covers found no internet: the Wii U is not connected, or its network has no internet (the cover server's name could not be looked up)                                 | Check the connection in the Wii U's System Settings > Internet, then fetch again                                                                                                   |
| OUR-0402 | Settings > Games, the line under the header                                     | Fetch covers reached the internet but not the cover server (thumbnails.libretro.com) three times in a row; the covers saved before it stay                                  | Try again later                                                                                                                                                                    |
| OUR-0901 | THIS BUILD IS BROKEN                                                            | Core variables too far apart for the recompiler (a build problem)                                                                                                           | Install a release build                                                                                                                                                            |
